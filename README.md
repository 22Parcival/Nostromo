# Nostromo

Nostromo est un système de gestion de contenu (CMS) léger et sur-mesure pour blog, conçu pour être simple à déployer, administrer et intégrer à n'importe quel site web.

## Fonctionnalités

- Authentification sécurisée via Discord OAuth2 avec liste blanche d'utilisateurs autorisés.
- Rédaction et rendu d'articles au format Markdown.
- Gestion et hébergement local des images.
- Interface d'administration moderne avec bascule entre affichage en mosaïque et en liste.
- Thèmes clair et sombre intégrés.
- Base de données légère SQLite ne nécessitant aucun serveur de base de données externe.
- API REST facilitant la récupération des articles depuis un autre front-end.
